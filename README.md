# SfmlGame-FantaPhrog
# 2D Survival Game (SFML)

## Overview
A real-time 2D survival-style game built in C++ using SFML. The player navigates the map, collects experience points, and avoids enemies while core gameplay systems are developed.

## Features
- Player movement using WASD controls
- Boundary collision to keep player within the game window
- Randomized spawning system for experience items
- Enemy spawning with collision-safe positioning
- Experience collection system with dynamic EXP tracking
- Animated EXP popup text that appears and floats upward on pickup

## Tech Stack
- C++
- SFML (Simple and Fast Multimedia Library)

## Gameplay Mechanics
- Players move freely around the map and collect EXP items
- EXP pickups increase the player's total experience
- Visual feedback is provided through floating text popups
- Enemies spawn in valid positions, avoiding overlap with player and items

## In Progress / Next Steps

## How to Run
1. Install SFML
2. Compile the project with a C++ compiler
3. Ensure the font file path is correctly set
4. Run the executable
